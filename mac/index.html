Jayraid for Mac

This is an early test build for Mac. Thank you for trying it! It needs a Mac with Apple silicon (M1 or newer) and macOS 12 or newer.

Downloads

Mac launcher

Game test build

The launcher needs your tester code. Mac versions for the launcher are on their way; until then the game test build lets you play right away.

The first start

  1. Double click the zip to unpack it. Move Jayraid Launcher into your Applications folder.
  2. macOS does not know Jayraid yet and blocks it the first time. Open Terminal and run this once: xattr -cr "/Applications/Jayraid Launcher.app" ~/Downloads/Jayraid-Game-Mac Or open it once, then go to System Settings, Privacy & Security, and click Open Anyway.
  3. Launcher: start it and enter your tester code.
  4. Game test build: open the folder Jayraid-Game-Mac and double click Blockwelt2. A Terminal window opens next to the game, that is normal.

Tell me how it runs

Does it start? Do the graphics, the sound and the mouse work? Screenshots help a lot, and if it crashes, a copy of what the Terminal window says. Send it on Discord or to jayraid.net@gmail.com.
