    The game

    A sandbox first. If you want more, there is a story with two bosses and an ending.

    Install

    1. Claim a place. You get your code and the launcher.
    2. Unpack the zip into its own folder.
    3. Start the launcher and enter your code. If Windows warns you: More info, then Run anyway.
    4. Click INSTALL, then PLAY. Updates take one click.
