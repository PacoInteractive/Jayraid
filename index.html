Castle ruins and the golem

A chained stone giant sleeps against the back wall. Be quiet! Once awake it becomes a boss fight: only the sabre knocks it over, only the wand hurts it on the ground.

Fire

Logs, planks, leaves and grass catch fire – from fire arrows, cannonballs or a burning player. Water and rain put it out.

Free inventory

Press I to unfold 48 honeycomb slots; drag, stack and swap everything. New worlds start empty.

Block throw for speedruns

Hold Q and right click to throw a block in an arc. The preview shows where it lands – every throw is the same at any frame rate.

A real ending

The bell creature on the pirate ships guards the wand. Once it falls, the traders come after you with hex-pixel fish.

Pixel workshop

Pixel the sabre, torch, wands and the fish yourself, hexagon by hexagon, and apply them straight to the running game.

  1. Claim a place

    Claim one of the tester places above. You get your personal code (also as a file) and Jayraid-Launcher.zip; unpack it into a folder of its own, e.g. Documents\Jayraid.

  2. Start and unlock

    Open Jayraid-Launcher.exe (if Windows asks: “More info → Run anyway”). Type in your code or drag the code file into the window.

  3. Install and play

    INSTALL, then PLAY. Every file is checked against the signed version list first.

New versions arrive by themselves: on start the launcher checks this site. If there is something new, the big button turns into UPDATE – one click and you are done. The launcher updates itself the same way.
